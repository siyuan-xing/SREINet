# Triple Pendulum Experimental Data

This folder contains the experimental data gathered from the triple pendulum system used in the SREINet paper.

This experimental data is sourced from the [Multi-Arm Pendulum Dataset](https://github.com/dynamicslab/MultiArm-Pendulum).

Credit: Kadierdan Kaheman, Urban Fasel, Jason J. Bramburger, Benjamin Strom, J. Nathan Kutz, Steven L. Brunton.
