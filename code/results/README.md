# Results Directory

This directory contains the results and analysis scripts for the SREINET paper. Each subdirectory corresponds to a specific dynamical system or experiment.

The identified ODEs are stored in the corresponding `output1.txt` file within each subdirectory.

The `Model_parser.py` script loads the text file and converts the ODEs into Python functions for simulation. Other post-training analysis files used to generate plots in the paper are also included.
