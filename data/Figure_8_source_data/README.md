# Figure 8 source data and reproduction

This directory contains the data-driven panels for the empirical triple-pendulum
example, the exact component images used in the manuscript, the current assembled
figure, and its Illustrator composition source.

The plotting scripts are copied without modification from
`results/triple_pendulum/`.  Run the loss and validation panels from this
directory so their original relative paths remain valid:

```bash
cd data/Figure_8_source_data
python bar_chart_loss.py
python plot_npz_time_history.py
```

These scripts write `loss_bar_chart_log_scale.png` and
`triple_pendulum_npz_time_history.png` in the current directory.  The training
trace is generated by the unchanged `draw_dataset.py`; it expects the public raw
file at its original relative location:

```text
TriplePendulum_Data/TripleDataFreeSwing_1_Dt_0_0001.mat
```

The compact training-trace NPZ records the downsample factor, original sampling
interval, and Savitzky-Golay parameters used to estimate angular acceleration.
The full raw experimental data are intentionally not duplicated in Git.  They
are available from the public
[`dynamicslab/MultiArm-Pendulum`](https://github.com/dynamicslab/MultiArm-Pendulum)
repository; this study used three files from `Datas/TriplePendulum`.

`components/` contains the exact three panels used in the manuscript.  The
plotting code is intentionally left in its original form, including filenames
and relative paths.  Dependencies: Python 3, NumPy, Matplotlib, seaborn, and
SciPy.
